# CineShare

Movie night, together. Host a movie from your computer and watch it in sync with friends — they join with just a stream name and password.

## Download

Get the latest Windows installer from the **[Releases page](https://github.com/jordanthurt/cineshare-releases/releases/latest)** (`CineShare-Setup-x.y.z.exe`).

Windows may show **"Windows protected your PC"** the first time, because the installer isn't code-signed yet. Click **More info → Run anyway**.

Once installed, CineShare updates itself automatically.

---

This repository only hosts installers and update files.
